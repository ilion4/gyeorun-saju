# 백도령 만세력 — 사주 운세 웹앱

궁합 / 재회운 / 신년운 등 원하는 풀이를 선택 → 정보 입력 → 토스 결제 → AI가 사주(만세력) 기반 풀이를 생성해 이메일로 자동 발송하는 웹앱입니다. PWA라 사용자가 홈 화면에 아이콘으로 저장해 앱처럼 쓸 수 있습니다.

## 폴더 구조
```
saju-app/
├─ public/            # 프론트엔드 (정적 파일 그대로 서빙)
│  ├─ index.html       # 선택→입력→결제→완료 4단계 플로우
│  ├─ app.js            # 상태관리 + 만세력 계산(브라우저용) + 토스 위젯
│  ├─ payment-success.html / payment-fail.html
│  ├─ manifest.json, sw.js, icons/  # PWA(홈화면 저장)
├─ lib/saju.js         # 만세력(사주 8자) 계산 로직 (서버용, app.js와 동일 로직)
├─ lib/pdf.js           # 풀이 결과를 PDF로 만드는 모듈 (pdfkit, 브라우저 불필요)
├─ assets/fonts/        # PDF에 임베드하는 한글 폰트(Pretendard)
├─ server.js           # Express 서버: 주문/결제승인/AI풀이생성/이메일발송
├─ package.json
└─ .env.example
```

## 로컬 실행
```bash
npm install
cp .env.example .env   # 아래 "키 발급" 참고해서 값 채우기
npm start               # http://localhost:3000
```
키를 하나도 안 채워도 실행은 됩니다 — 결제는 토스 **테스트 키**로, AI 풀이는 **데모 텍스트**로, 이메일은 **콘솔 출력**으로 대체되어 전체 흐름을 확인할 수 있어요.

## 실제 서비스로 만들려면 (키 발급 3곳)

**1. 토스페이먼츠** — https://developers.tosspayments.com
- 회원가입 → 내 상점 → API 키 발급 → `TOSS_SECRET_KEY`에 입력
- `public/app.js`의 `CLIENT_KEY`도 발급받은 클라이언트 키로 교체
- 지금은 테스트 키가 들어있어서 결제창은 뜨지만 실제 승인은 안 됩니다

**2. Anthropic API (AI 풀이 생성)** — https://console.anthropic.com
- API 키 발급 → `ANTHROPIC_API_KEY`에 입력
- `server.js`의 `callClaude()`에서 프롬프트를 다듬으면 톤/분량 조절 가능

**3. 이메일 발송** — Resend(https://resend.com) 추천, 또는 Gmail SMTP
- Resend: 도메인 인증 후 API 키를 SMTP_USER/PASS 자리에 맞게 설정 (또는 Resend SDK로 교체)
- `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM` 채우면 바로 발송됩니다

## 자동 재시도 & 관리자 로그 페이지

**발송 실패 시 자동 재시도**: AI 풀이 생성이나 이메일 발송이 실패하면(네트워크 오류, API 일시 장애 등) 자동으로 1분 → 5분 → 15분 뒤 다시 시도합니다. 3번 다 실패하면 자동 재시도는 멈추고 관리자가 수동으로 재발송해야 해요. 서버가 재시작돼도 밀린 재시도는 알아서 다시 예약됩니다.

**관리자 로그 페이지**: `.env`에 `ADMIN_PASSWORD`를 정해서 채운 뒤, 배포된 주소 뒤에 `/admin.html`을 붙여 접속하세요 (예: `https://내사이트.com/admin.html`). 여기서:
- 전체 주문 수 / 발송완료 / 실패 건수 / 누적 결제금액을 한눈에 확인
- 각 주문의 결제 여부, 발송 상태, 시도 횟수, 실패 사유를 표로 확인
- 자동 재시도가 다 끝났는데도 실패한 주문은 **"재발송" 버튼**을 눌러 바로 재전송

주문 기록은 `data/orders.json` 파일에 저장돼요. **배포 플랫폼에 따라 이 파일이 재배포/재시작 시 초기화될 수 있으니**, 운영 규모가 커지면 이 부분만 SQLite나 PostgreSQL로 교체하는 걸 권장합니다 (`lib/store.js`의 함수들만 DB 버전으로 바꾸면 나머지 코드는 그대로 써도 됩니다).

## 카카오톡 발송으로 확장하려면
이메일이 먼저 도는 걸 확인한 뒤 추가하는 걸 추천해요.
1. 카카오 비즈니스 채널 개설 + 알림톡 발신 프로필 등록 (심사 1~3일 소요)
2. 알림톡 템플릿 사전 등록 (내용에 변수 `#{이름}`, `#{풀이내용}` 등 지정)
3. NHN Cloud, 알리고, 솔라피 같은 알림톡 대행 API 중 하나 계약
4. `server.js`의 `sendEmail()` 옆에 `sendKakao()` 함수를 추가해 `generateAndSend()`에서 함께 호출

## 생년월일시 입력 옵션

- **양력/음력**: 각 사람마다 토글로 선택. 음력을 고르면 `korean-lunar-calendar`(오픈소스, 한국천문연구원 기반 데이터) 라이브러리로 서버에서 양력으로 자동 변환한 뒤 계산해요. 음력 윤달 여부도 체크 가능
- **태어난 시간**: 3가지 방식 지원
  - 정확히 — 시:분 직접 입력
  - 대략(시진) — 자시~해시 12개 버튼 중 선택 (예: "어르신께 축시생이라고 들었어요")
  - 모름 — 시주 없이 진행 (정오 기준으로 참고 계산, 결과에도 "시간 모름"으로 명시)

## 가격 옵션 (간략하게 / 심도있게)

운세 종류마다 두 가지 분량으로 판매합니다. `public/app.js` 상단의 `TIER_BRIEF` / `TIER_DEEP`, `FORTUNES`의 `priceBrief`/`priceDeep`에서 가격과 글자수를 조절할 수 있어요.

| 옵션 | 분량 | 특징 |
|---|---|---|
| 간략하게 | 약 900~1,300자 (A4 약 1장) | 소제목 없이 핵심만 |
| 심도있게 | 약 4,200~5,200자 (A4 약 4장) | 원국풀이·심층해석·연도별 흐름·주의점 등 소제목 구성 |

가격/글자수를 바꾸면 서버(`server.js`)가 주문에 담긴 값을 그대로 읽어 프롬프트와 `max_tokens`를 자동으로 맞춰 생성합니다 — 서버 코드는 따로 안 건드려도 돼요.

## 풀이는 PDF로 만들어 발송돼요

이메일 본문은 짧은 안내문만 담고, 실제 풀이는 **PDF 파일로 첨부**됩니다.

- 구성: 표지(사주 8자 도장) → 목차 → 본문 섹션 → 월별운세(심도 티어만, 12개월) → 마무리 총평
- 디자인: 웹앱과 동일한 네이비+금색+도장 컨셉을 그대로 반영
- AI(`callClaude`)가 JSON 형식으로 구조화된 풀이를 응답하면 `lib/pdf.js`(`generateFortunePdf`)가 그 내용을 받아 PDF를 만들어요
- **puppeteer/크로미움을 쓰지 않고 pdfkit만으로 렌더링**해서, Railway 같은 가벼운 호스팅에서도 별도 설정 없이 안정적으로 동작합니다
- AI가 JSON 형식을 어긋나게 응답하는 드문 경우에도, 원문을 그대로 하나의 섹션에 담아 PDF는 항상 만들어지도록 안전장치를 넣어뒀어요

## 만세력 계산 정확도 안내
`lib/saju.js` 상단 주석 참고 — 일주는 정확하지만, 년주/월주 경계에 쓰는 절기(입춘/경칩 등) 날짜는 **매년 거의 같은 평균값을 쓴 근사치**입니다. 상용 서비스 정밀도가 필요하면 한국천문연구원(KASI) 절기 API 또는 정밀 천문 계산 라이브러리로 교체하세요. (음력↔양력 변환은 별도 라이브러리로 이미 정확하게 처리됩니다.)

## 배포
Node 18+ 지원하는 아무 곳이나 가능합니다 (Render, Railway, Fly.io, 자체 서버 등).
- 정적 파일(`public/`)과 서버(`server.js`)가 한 프로세스에서 같이 돕니다 — 별도 프론트 배포 불필요
- 배포 후 도메인이 HTTPS인지 꼭 확인하세요 (PWA 설치, 토스 결제 모두 HTTPS 필수)
- 주문 저장이 지금은 메모리(Map)라 서버 재시작 시 날아갑니다 — 배포 전 SQLite/PostgreSQL 등으로 교체 권장
